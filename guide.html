使用教程

从材料准备到开机，按顺序走一遍。遇到问题先看第八节的常见问题。

注意：
软件的作用是模拟电脑 PC 给另外一台 Android 手机进行线刷或调试。

一、材料准备

  • 需要 OTG 转接头 / 双 C 线 / 数据线
使用 OTG 转接头和双 C 线时要确保连接稳定。推荐 OTG——双 C 线会触发快充协议，容易在线刷中快速掉电。OTG 转接头也建议用品牌货，部分第三方转接头连接不稳定。

二、设备连接

  • 检查本机设置中是否有「OTG」选项，有就打开
  • 把 OTG 转接头 / 双 C 线插入设备

如果需要识别系统：

  • 另外一台手机在设置中打开「USB 调试」（用于其他模式则不用开启）
  • 另一台手机会弹出界面 → 勾选「一律允许使用这台计算机进行调试」→ 点「允许」
如果使用双 C 线，确保另外一台手机充上电才能正常识别。如果无法正常连接，请判断是否弹出 USB 通知——如果没有，代表连接不稳定或数据线不支持数据传输，请尝试更换数据线 / OTG 转接头后重试。

三、欧加线刷

支持机型：OPPO / realme / 一加

  • 在导航栏「工具」中打开「Payload.bin 解压」
  • 选择解压出来的 payload.bin
  • 按设备性能调整线程数，例如骁龙 845、天玑 1000+ 这类低性能设备建议设成 10 线程
  • 点「开始下载 / 解压」
  • 解压完返回首页，点「欧加真线刷」
  • 点旁边的文件夹图标，选择解压好的镜像目录 /storage/emulated/0/ChenAxic/payload_bin/
  • 如果设备丢失 fastboot 且无法进入，请使用「纯 FastbootD」；设备能正常进入 fastboot 但无法进入 fastbootD，请使用「常规线刷」；如果两者都没什么问题，推荐使用「纯 FastbootD」，无需二次重启
如果多次出现 my_ 开头的镜像，或 odm、system、system_dlkm、system_ext、vendor、vendor_dlkm、product、odm_dlkm 无法正常刷入，将设备重启到 fastboot → 使用「分区 super 修复」，再进行线刷

基本上没问题的话刷完就能开机。

四、小米线刷

支持机型：小米 / 红米

确保线刷包中含 .sh 执行脚本，否则无法线刷。
  • 把设备重启到 fastboot
  • 首页进入「小米线刷」，选择已解压好的刷机包
  • 选择「flash_all.sh 不回锁 BL + 清除数据」
  • 如果出现「Missmatching image and device」，请查看线刷包是否匹配
  • 如果卡在正在执行，请将设备重新进 fastboot 模式再进行线刷

五、ADB Sideload 卡刷

Sideload 的原理是将卡刷包变成线刷包。

如何进入 Sideload 模式：

Recovery 操作步骤

  • TWRP：打开高级 → ADB Sideload → 下方滑动开启
  • 橙狐：点击下方三条杠 → ADB Sideload → 下方滑动开启
  • 类原生 Recovery：Apply update → Apply from ADB

执行线刷：

  • 首页进入「ADB Sideload」
  • 选择卡刷包
  • 点「开始刷入」

六、刷 Root

方案 A：已修补好的镜像

  • 准备修补好的 boot.img / init_boot.img
  • 把设备重启到 fastboot 模式
  • 首页进入「刷写分区」
  • 点击「选择镜像 (img)」
  • 根据原来的镜像名刷入（二选一）：
  • 「一键刷入 init_boot (a+b)」
  • 「刷入 boot」
  • 点击即可刷入

方案 B：刷入 KernelSU（LKM）

  • 获取未修补的 boot.img / init_boot.img 原版镜像
  • 把设备重启到 fastboot 模式
  • 首页进入「刷入 KernelSU」
  • 选择内核版本
  • 点「选择 init_boot.img / boot.img」，选择未修补的镜像
  • 点「修补」
  • 修补完按原镜像名称刷入

七、高通 QDL

先选择「机型 / 处理器」，App 会自动填入对应引导文件；如果引导无法使用，可手动更换。

9008 EDL 端口不支持热拔插，全程操作需要保持连接稳定。如果出现断联的情况，需要手动重启设备才能正常授权写读操作。

如何进入 9008（EDL）

  • 骁龙 888 及以上：关机状态下同时按住「音量下 + 音量上」，再插入数据线，可自动进入 9008 端口
  • 通过 ADB：首页「重启设备」中点击「9008」，直接重启到 EDL
  • 通过 fastboot：fastboot oem edl
fastboot oem edl 仅支持老旧设备，新设备不支持。

1. 欧加 9008 线刷

  • 需要先完成「欧加真 VIP 授权」才能刷写
  • 把线刷包解压到手机存储
  • 用「QFIL 线刷」点「浏览」，选择解压好的线刷包目录
  • 点「欧加构建 super.img」
  • 如需清除数据，把「userdata.img 会自动清除数据」关掉
  • 构建完点「刷入」

2. 欧加全量包线刷

  • 需要先完成「欧加真 VIP 授权」才能刷写
  • 把全量包用「Payload.bin 解压」处理
  • 进入「欧加真全量包线刷」，点「选择镜像目录」
  • 选择解压好的目录 /storage/emulated/0/ChenAxic/payload_bin
  • 点「开始线刷」
会自动构建 super.img，速度取决于设备性能。构建结果会被复用，下次不会重复构建。

3. 联想 / 小米 / 红魔等品牌 9008 深刷

  • 用「QFIL 线刷」点「浏览」，选择解压完的线刷包
  • 如需清除数据，把「userdata.img 会自动清除数据」关掉
  • 设置完成点「刷入」

八、常规问题

  • 部分的设备重启到 fastboot 有概率无法识别，请手动重启，重启期间需拔掉数据线，完全进入 fastboot 后再插上数据线，才能识别
  • 执行 fastboot 命令时，如果提示 <waiting for any device>，翻译过来的意思是「等待任何设备」，说明没连上设备
  • 在线刷或刷写镜像时，出现卡住的情况，请将设备重新进入 fastboot 模式重新刷写即可（原因是前面多次刷镜像失败导致的问题）
