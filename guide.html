使用教程

从材料准备到开机，按顺序走一遍。遇到问题先看第八节的常见问题。

先理解两件事：
1. 这个 App 的作用是把你的手机模拟成一台电脑，通过 OTG 或数据线去刷写另一台手机。所以「本机」是指操作端，「目标机」才是被刷写的设备。
2. 本机必须已授予 Root 权限，否则刷写功能无法使用。首次启动的引导页会检测并提示授权。

一、材料准备

  • OTG 转接头，或双 C 线 / 数据线
  • 稳定供电的环境（线刷耗时较长）
使用 OTG 转接头和双 C 线时要确保连接稳定。推荐 OTG——双 C 线会触发快充协议，容易在线刷中快速掉电。OTG 转接头也建议用品牌货，部分第三方转接头连接不稳定。

二、设备连接

  • 检查本机设置中是否有「OTG」选项，有就打开
  • 把 OTG 转接头 / 双 C 线插入设备

如果需要识别系统，还要在目标机上打开 USB 调试：

  • 目标机设置中打开「USB 调试」（仅用于刷机等其他模式时不需要）
  • 目标机弹出授权界面 → 勾选「一律允许使用这台计算机进行调试」→ 点「允许」
如果用双 C 线，要确保目标机在充电状态才能正常识别。如果连不上，先看目标机有没有弹出 USB 通知——没有则说明连接不稳定或线材不支持数据传输，换根线或换个转接头再试。

三、欧加线刷

支持机型：OPPO / realme / 一加

  • 在导航栏「工具」中打开「Payload.bin 解压」
  • 选择解压出来的 payload.bin
  • 按设备性能调整线程数，例如骁龙 845、天玑 1000+ 这类低性能设备建议设成 10 线程
  • 点「开始下载 / 解压」
  • 解压完返回首页，点「欧加真线刷」
  • 点旁边的文件夹图标，选择解压好的镜像目录 /storage/emulated/0/ChenAxic/payload_bin/
两种模式怎么选：设备丢失 fastboot 且进不去 → 用「纯 FastbootD」；能进 fastboot 但进不了 fastbootD → 用「常规线刷」；两者都正常 → 推荐「纯 FastbootD」，不用二次重启。
如果多次出现 my_ 开头的镜像，或 odm、system、system_dlkm、system_ext、vendor、vendor_dlkm、product、odm_dlkm 无法正常刷入，把设备重启到 fastboot → 用「分区 super 修复」→ 再重新线刷。

正常情况下刷完就能开机。

四、小米线刷

支持机型：小米 / 红米

确保线刷包中含 .sh 执行脚本，否则无法线刷。
  • 把设备重启到 fastboot
  • 首页进入「小米线刷」，选择已解压好的刷机包
  • 选择 flash_all.sh（不回锁 BL + 清除数据）
出现 Missmatching image and device → 检查线刷包是否匹配该机型。卡在「正在执行」→ 把设备重新进 fastboot 模式再刷一次。

五、ADB Sideload 卡刷

Sideload 的原理是把卡刷包当线刷包刷进去。

进入 Sideload 模式：

  • TWRP：打开「高级」→「ADB Sideload」→ 下方滑块滑动开启
  • 橙狐：点下方三条杠 →「ADB Sideload」→ 下方滑块滑动开启
  • 类原生 Recovery：「Apply update」→「Apply from ADB」

执行刷入：

  • 首页进入「ADB Sideload」
  • 选择卡刷包
  • 点「开始刷入」

六、刷 Root

方案 A：已修补好的镜像

  • 准备修补好的 boot.img / init_boot.img
  • 把设备重启到 fastboot 模式
  • 首页进入「刷写分区」
  • 点「选择镜像 (img)」
  • 按原镜像类型二选一：「一键刷入 init_boot (a+b)」或「刷入 boot」
  • 点击即可刷入

方案 B：刷入 KernelSU（LKM）

  • 获取未修补的 boot.img / init_boot.img 原版镜像
  • 把设备重启到 fastboot 模式
  • 首页进入「刷入 KernelSU」
  • 选择内核版本
  • 点「选择 init_boot.img / boot.img」，选择未修补的镜像
  • 点「修补」
  • 修补完按原镜像名称刷入

七、高通 QDL

先选「机型 / 处理器」，App 会自动填入对应引导文件；引导不可用时可手动更换。

9008 EDL 端口不支持热拔插，全程要保持连接稳定。一旦断联，需要手动重启设备才能恢复正常读写授权。

如何进入 9008（EDL）

  • 骁龙 888 及以上：关机状态下同时按住「音量下 + 音量上」，再插入数据线，可自动进入 9008 端口
  • 通过 ADB：首页「重启设备」中点击「9008」，直接重启到 EDL
  • 通过 fastboot：fastboot oem edl
fastboot oem edl 仅支持老旧设备，新设备不支持。

1. 欧加 9008 线刷

  • 需要先完成「欧加真 VIP 授权」才能刷写
  • 把线刷包解压到手机存储
  • 用「QFIL 线刷」点「浏览」，选择解压好的线刷包目录
  • 点「欧加构建 super.img」
  • 如需清除数据，把「userdata.img 会自动清除数据」关掉
  • 构建完点「刷入」

2. 欧加全量包线刷

  • 需要先完成「欧加真 VIP 授权」才能刷写
  • 把全量包用「Payload.bin 解压」处理
  • 进入「欧加真全量包线刷」，点「选择镜像目录」
  • 选择解压好的目录 /storage/emulated/0/ChenAxic/payload_bin
  • 点「开始线刷」
会自动构建 super.img，速度取决于设备性能。构建结果会被复用，下次不会重复构建。

3. 联想 / 小米 / 红魔等品牌 9008 深刷

  • 用「QFIL 线刷」点「浏览」，选择解压完的线刷包
  • 如需清除数据，把「userdata.img 会自动清除数据」关掉
  • 设置完成点「刷入」

八、常见问题

  • 设备重启到 fastboot 后识别不到 → 手动重启设备，重启期间拔掉数据线，完全进入 fastboot 后再插线，才能识别。
  • 提示 <waiting for any device> → 意思是「等待任何设备」，即没连上目标机。
  • 刷写卡住不动 → 把设备重新进入 fastboot 模式再刷一次。通常是前面多次刷镜像失败导致的。
  • my_ 开头镜像刷不进去 → 重启到 fastboot，用「分区 super 修复」后再线刷。
  • 刷完开不了机 → 确认刷入的分区完整（系统、boot、vbmeta 都应刷入），必要时重刷 super 分区。
